# همتوار شخصی

برنامه‌ی مدیریت کار (ماتریس آیزنهاور)، دخل‌وخرج، قسط و چک، عادت‌ها و اهداف — فارسی، راست‌به‌چپ، تقویم شمسی.
شناسه‌ی اندروید: `ir.hamtavar.personal`، حداقل Android 6.

## ساختار

- `src/` — رابط کاربری (React + Vite + Tailwind). نقطه‌ی ورود: `src/main.tsx`.
- `server.ts` — سرور Express: ورود پیامکی، پشتیبان ابری، بنر، نسخه، دیتاست.
- `www/` — خروجی ساخته‌شده‌ی رابط کاربری که داخل APK قرار می‌گیرد (با `npm run build:android` ساخته می‌شود؛ دستی ویرایش نشود).
- `android/` — پوسته‌ی WebView اندروید.
- `data/` — داده‌ی زمان اجرا. فقط `ads.json` و `version.json` در گیت هستند؛ کاربران، پشتیبان‌ها و لاگ‌ها هرگز کامیت نمی‌شوند.

## اجرا

```
npm install
cp .env.example .env     # مقادیر را پر کنید
npm run dev              # http://localhost:3000
```

برای حالت واقعی: `npm run build` و سپس `NODE_ENV=production npm start`.

### تنظیمات سرور (`.env`)

| متغیر | توضیح |
|---|---|
| `SESSION_SECRET` | کلید امضای نشست‌ها؛ در production الزامی (حداقل ۳۲ نویسه‌ی تصادفی). |
| `SMS_IR_API_KEY`، `SMS_TEMPLATE_ID` | وب‌سرویس Verify سامانه‌ی SMS.ir برای کد ورود. |
| `ADMIN_MOBILES` | شماره‌هایی که پنل مدیریت را می‌بینند (با ویرگول جدا شوند). |
| `CORS_ORIGINS` | مبدأهای مجاز؛ پیش‌فرض، WebView اپ اندروید. |
| `TRUST_PROXY` | اگر سرور پشت پراکسی است `1` بگذارید تا محدودیت نرخ درست کار کند. |
| `DATA_DIR` | محل ذخیره‌ی داده (پیش‌فرض `./data`). |
| `SFTP_HOST`، `SFTP_USERNAME`، `SFTP_REMOTE_DIR` | مقصد انتشار APK از پنل مدیریت (اختیاری). |

بدون `SMS_IR_API_KEY`، سرور **توسعه** کد را روی صفحه‌ی ورود نشان می‌دهد؛ سرور **production** هرگز کد را برنمی‌گرداند.

## امنیت و حریم خصوصی

- ورود فقط با کد پیامکی؛ کد یک‌بارمصرف، ۳ دقیقه اعتبار، حداکثر ۵ تلاش، و محدودیت تعداد درخواست برای هر شماره و هر IP.
- پس از ورود، سرور یک توکن امضاشده می‌دهد. پشتیبان ابری هر کاربر فقط با توکن خود او خوانده و نوشته می‌شود.
- تغییر بنر، نسخه، انتشار SFTP و دریافت دیتاست فقط برای `ADMIN_MOBILES`.
- داده‌ی هر کاربر روی دستگاه در بخش جدا (`hp_state_<mobile>`) می‌ماند و با خروج از حساب به کاربر بعدی منتقل نمی‌شود.
- لاگ رفتاری فقط نوع و زمان عملیات است، با شناسه‌ی مستعار به‌جای شماره، و از تنظیمات قابل خاموش‌کردن است.

## ساخت اندروید

JDK 17 و Android SDK 34 لازم است.

```
npm run build:android                       # به‌روزرسانی www
cd android
./gradlew assembleDebug -PapiBase=https://آدرس-سرور-شما
```

- با `apiBase`، اپ فقط به همان سرور (https) وصل می‌شود و ورود پیامکی و پشتیبان ابری فعال است.
- بدون `apiBase`، اپ کاملاً آفلاین است: ورود ندارد و همه‌چیز روی همان گوشی می‌ماند.
- در GitHub Actions مقدار را در متغیر مخزن `API_BASE` بگذارید.

مجوزها: `INTERNET` (فقط برای سرور تنظیم‌شده) و `RECEIVE_SMS` (تشخیص پیامک بانکی روی خود دستگاه).

## محدودیت‌های فعلی

- پشتیبان ابری دستی است (دکمه‌ی «ذخیره در ابر» در تنظیمات)؛ همگام‌سازی خودکار ندارد.
- یادآوری سررسید قسط و چک فقط داخل برنامه نمایش داده می‌شود (اعلان پس‌زمینه ندارد).
- فایل پشتیبان JSON رمزگذاری نشده است.
