# همتوار شخصی - نسخه اولیه اندروید ۰٫۱

شناسه مستقل `ir.hamtavar.personal`، کد نسخه 1، حداقل Android 6. لوگوی مربع و فونت کلمه از همتوار، رابط راست‌به‌چپ و تم روشن/تیره. پوسته سبک HTML/CSS/JS آفلاین داخل یک Activity اندروید است؛ به دلیل استفاده مجدد از الگوی WebView محصول و نیاز نداشتن به سرور، چارچوب وب دیگری اضافه نشده است.

کار و زیرکار، تاریخ نسبی/شمسی و ساعت، اتصال کار به هدف، ماتریس آیزنهاور (فوری/مهم) با آموزش، هزینه و درآمد به تومان، دسته‌بندی و بودجه ماهانه، قسط ماهانه و چک با یادآوری سررسید داخل برنامه، هدف عددی و پیشرفت، پلنر ۳۰روزه، عادت روزانه/شنبه تا پنجشنبه/جمعه با تقویم ماهانه و سوابق، تبدیل عادت به کار روزانه یا یک‌روز‌درمیان.

اطلاعات Android در SharedPreferences خصوصی و با commit موفق ذخیره می‌شود. اطلاعات در هیچ سروری ارسال نمی‌شود. حذف برنامه داده‌ها را پاک می‌کند؛ پیش از حذف، از تنظیمات پشتیبان JSON بگیرید. بازیابی پس از اعتبارسنجی و تأیید جایگزینی انجام می‌شود. فایل پشتیبان رمزگذاری نشده است و باید امن نگهداری شود. نمایش محتوای APK با WebViewAssetLoader روی origin ثابت است؛ مرور خارجی و دسترسی شبکه مسدود است. هیچ مجوز مخاطب، مکان، دوربین یا اینترنت درخواست نمی‌شود.

محدودیت‌های نسخه اولیه: اعلان پس‌زمینه، اتصال بانکی، همگام‌سازی ابری، قفل رمز/بیومتریک، ورود حساب و مهاجرت داده اپ شرکتی ندارد. یادآوری سررسید قسط و چک فقط با بازکردن برنامه در بخش دخل‌وخرج نمایش داده می‌شود. پیشرفت عددی اهداف دستی است و تعداد کارهای انجام‌شده هدف جدا نمایش داده می‌شود؛ بودجه یک سقف ماهانه ثابت است، نه حساب بانکی واقعی.

## اجرای آزمون‌ها

با Node.js، ابتدا `npm install` و `npx playwright install chromium` و سپس `npm test` را اجرا کنید. برای استفاده از Chrome نصب‌شده، متغیر `CHROME_BIN` را با مسیر آن تنظیم کنید؛ `PLAYWRIGHT_MODULE` نیز برای استفاده از نصب موجود Playwright اختیاری است. screenshotهای آزمون فقط دادهٔ ساختگی دارند و وارد Git نمی‌شوند.

## ساخت اندروید

JDK 17 و Android SDK 34 لازم است. پروژهٔ `android` را در Android Studio باز کنید یا پس از تنظیم `ANDROID_HOME`/`android/local.properties`، داخل `android` دستور `./gradlew assembleRelease` (ویندوز: `gradlew.bat assembleRelease`) را اجرا کنید. Gradle wrapper و AGP نسخهٔ 8.2.1 هستند. فایل‌های `www` هنگام ساخت به‌صورت خودکار در assets اپ قرار می‌گیرند.

خروجی در `android/app/build/outputs/apk/release/app-release-unsigned.apk` است. امضای انتشار باید جداگانه با کلید مالک انجام شود؛ کلید خصوصی و رمز امضا، تنظیم SDK محلی و فایل APK در مخزن قرار نمی‌گیرند. این انتقال مخزن، APK تازه‌ای نمی‌سازد یا روی سایت منتشر نمی‌کند.

سورس: www/index.html، www/app.css، www/app.js؛ Android: android/app/src/main/java/ir/hamtavar/personal/MainActivity.java. سایت شرکتی، دیتابیس شرکت‌ها و دیمه تغییر نکرده‌اند. انتخابگر فایل اندروید و ماندگاری اطلاعات پس از بستن واقعی برنامه نیاز به آزمون روی گوشی دارد؛ آزمون‌های مرورگر جای آن را نمی‌گیرد.
